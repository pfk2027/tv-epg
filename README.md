# tv-epg

Урезанная телепрограмма (XMLTV) для TiviMate на слабом Android TV. Полный файл источника
(`iptvx.one/epg/epg_lite.xml.gz`, 16 МБ) телевизор не успевает разобрать, поэтому скрипт оставляет
только нужные каналы, окно от -3 ч до +72 ч, и в передаче только название и жанр.

Сборка: GitHub Actions два раза в сутки (`.github/workflows/epg.yml`) или вручную `python -I build_epg.py`.

Адрес для TiviMate:

    https://raw.githubusercontent.com/pfk2027/tv-epg/main/epg.xml.gz

Добавить канал: дописать его `tvg-id` в `channels.txt` (одна строка — один id), закоммитить.
Скрипт завершается с ошибкой, если осталось меньше 50 каналов или 1000 передач, — старый файл не затирается.
